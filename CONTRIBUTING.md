# Contributing

Thank you for looking at Zyvor Retail. This repository is the **public website**; the application source is private. That shapes how you can help.

## What helps most

- **Feedback from the demo or a pilot.** What worked, what confused you, what you wanted to see. Use the **Feedback** issue form, or email [sales@zyvor.dev](mailto:sales@zyvor.dev?subject=Zyvor%20Retail%20feedback).
- **Reports that the website or the demo does not work.** Use the **Bug report** form and say which browser and device.
- **Security reports** go to [security@zyvor.dev](mailto:security@zyvor.dev), never into a public issue. See [SECURITY.md](SECURITY.md).

## Please never include

**Customer data, passwords, session cookies or payment details.** Not in an issue, not in a screenshot. Everything in the demo is fictional; keep it that way.

## Pull requests

Pull requests for the site's pages are not generally accepted. If you spot a mistake on the site or in these docs, open an issue and we will fix it.
