# Security policy

## Reporting a vulnerability

Email **[security@zyvor.dev](mailto:security@zyvor.dev?subject=Zyvor%20Retail%20security)**. Please do **not** open a public issue for a vulnerability.

Include what you found, where (the website, the demo, or a pilot copy), the version, and the steps to reproduce it. **Do not include customer data, passwords, session cookies or payment details** in a report.

## Scope

- The Zyvor Retail website and the files in this repository.
- The shared live demo, which runs fictional data on a test machine.

There is no application source in this repository, so reports about source code cannot be handled here; send them by email and we will route them.

## What to expect

Zyvor Retail is a pilot release (0.6.2) with no independent security review yet. See the [security overview](docs/SECURITY-OVERVIEW.md) for the controls in place and what has not been done.
